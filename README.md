# DevPortfolio – João Silva (Full-Stack Developer)

Portfólio profissional moderno e minimalista desenvolvido com **Next.js 14 (App Router)**, **Tailwind CSS** e **TypeScript**.

## Funcionalidades
- 🚀 **Homepage:** Apresentação pessoal, bio e links sociais (GitHub, LinkedIn).
- 🛠️ **Habilidades Técnicas & Experiência:** Timeline profissional e badges de competências.
- 💻 **Galeria de Projetos:** Cards com filtros por categoria (Frontend, Backend, Full-Stack).
- ✉️ **Formulário de Contato:** Integração serverless para envio de e-mails.

## Como Executar

```bash
cd apps/frontend
npm install
npm run dev
```

Acesse a aplicação em `http://localhost:3000`.
